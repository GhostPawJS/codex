# Pages Demo

The demo is built with `npm run demo:build` (output `demo/`) and published at https://codex.ghostpaw.dev/docs/. The landing page https://codex.ghostpaw.dev/ is maintained separately.

The demo is a small browser shell over the same Codex package surface.

It uses sql.js in the browser, initializes the schema locally, seeds a tiny demo session, and renders status, flags, and recall through the same direct-code reads and writes.
